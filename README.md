# Sierra / Quectel 2.5GbE PoE modem appliance

A fresh, cost-focused MCU-based design. No CM4 or CM5.

## Requirements

- Sierra/Semtech EM919x and Quectel RM5x modem support.
- 2.5GbE with standards-based isolated PoE input.
- Reliable unattended operation: connect a PoE Ethernet cable and obtain
  cellular WAN service with a supported modem, antennas and provisioned SIM.
- Low total assembled cost.

[REQUIREMENTS.md](REQUIREMENTS.md) defines the current scope and architecture
questions. No MCU or packet-forwarding architecture is selected yet; there is
no current schematic, PCB or qualified hardware.

Work on `master`. Previous designs are available only in Git history;
the final pre-restart hardware checkpoint is `c81dc27`.
