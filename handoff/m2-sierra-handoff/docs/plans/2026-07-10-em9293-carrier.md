# EM9293 Forced-USB Test Carrier — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Design a fabricable 4-layer PCB (EasyEDA Pro → JLCPCB) that runs a Sierra EM9293 in forced-USB SuperSpeed mode for bench bring-up and throughput testing.

**Architecture:** A single M.2 3052 Key-B carrier. Dual USB-C (data + PD power), an autonomous PD sink feeding a 4 A buck to 3.3 V, a 1.8 V LDO for the interface-select strap, a USB-C orientation mux for both-way SuperSpeed, nano-SIM, and status/power LEDs. All modem pin decisions come from the verified spec.

**Tech Stack:** EasyEDA Pro (desktop), JLCPCB fabrication + PCBA assembly (native LCSC parts + one-click order).

**Spec:** `docs/superpowers/specs/2026-07-10-em9293-carrier-design.md` (read it first — every pin/value below traces to it).

**Tooling & version control (EasyEDA Pro):** Design in **EasyEDA Pro**. Parts come from the **LCSC library** with vendor-vetted symbols+footprints — no footprint authoring. Global remaps for the steps below:
- **"ERC"** → EasyEDA **Design → Check DRC on the schematic** (net/connectivity check).
- **"DRC"** → EasyEDA **PCB DRC**.
- **"git commit"** → EasyEDA auto-saves; take a **Pro version snapshot** (History panel) at that milestone. Git in this repo tracks the **spec/plan/docs** and **exported fab artifacts** (Gerbers/BOM/CPL), not the live EDA database — commit exports at Tasks 6, 10, 11.

## Global Constraints

- **Modem pin voltage limits (hard):** `PCIE_DIS` pin 20 ≤ 2.10 V (use 1.8 V rail only). `Full_Card_Power_Off_N` pin 6 high = 1.35–4.4 V. `VBUS_SENSE` pin 22 = 2.0–5.25 V. Never drive `RESET_N` pin 67 high.
- **Power rail:** 3.3 V, ≥4 A capacity, ripple ≤100 mVpp, bulk caps at the M.2 VCC pins.
- **PCB:** 4-layer, controlled impedance. USB differential pairs = **90 Ω**; USB3 SS = 90 Ω diff, length-matched.
- **USB3 AC-coupling:** 220 nF series caps on module RX pair (pins 35/37) only; TX pair (29/31) direct.
- **Interface latched at boot:** straps (`PCIE_DIS` high, `Full_Card_Power_Off_N` high) must be stable before/as the module powers.
- **Antennas:** on-module; populate all 4 for valid operation. No RF on the PCB.
- **Every task ends with ERC or DRC clean (as applicable) + a git commit.**

### Task 2: Power subsystem schematic (PD sink → buck → 3.3 V + 1.8 V)

**Files:**
- Modify: `em9293-carrier.kicad_sch` (add a `Power` hierarchical sheet)

**Interfaces:**
- Consumes: nothing (root of the power tree).
- Produces: nets **`+3V3`** (≥4 A), **`+1V8`**, **`GND`**, **`VBUS_PD`** (9–12 V from PD), **`PG_3V3`** (power-good, optional).

- [ ] **Step 1: Define the ERC intent (the "test")**

Write down the pass condition to check at end of task: no unconnected power-input pins, `+3V3`/`+1V8`/`GND` each driven by exactly one source symbol, no ERC power-flag errors.

- [ ] **Step 2: USB-C #2 (PD) + CH224K decoy**

Place USB-C #2 receptacle (power-only). Wire connector CC1→CH224K pin 7, CC2→pin 6. CH224K VDD (pin 2) ← J2 VBUS via **1 kΩ** + **1 µF** to GND. VBUS-sense (pin 8) ← J2 VBUS via **10 kΩ**. **CFG1 (pin 9) → 24 kΩ to GND** (= request 12 V); CFG2/CFG3/DP = NC. PG (pin 10) → 10 kΩ pull-up to VDD (+ optional PD-OK LED). Route J2 connector VBUS → `VBUS_PD` (buck input) **directly** — no load switch (charger holds 5 V until contract, then 12 V; buck input range covers both).

- [ ] **Step 3: Buck 12 V → 3.28 V / 4 A (TPS565201)**

Place TPS565201 (4.5–17 V in, 5 A, VFB = 0.760 V). Feedback for 3.3 V: `Vout = 0.760·(1+R1/R2)` → **R1 (top) = 33.2 kΩ 1%, R2 (bot) = 10.0 kΩ 1%** → **3.28 V**. Inductor **2.2 µH**, Isat ≥6 A, low DCR. Input **2×10 µF/25 V X7R** + 0.1 µF; output **2×22 µF/10 V X7R** (D-CAP2). **EN: 1 MΩ from VBUS_PD→EN** (with the internal 245 kΩ pulldown, turn-on ≈8 V) so the buck stays off at the 5 V default and only starts after the CH224K negotiates 12 V. Route output to `+3V3`.

- [ ] **Step 4: Bulk bank + 1.8 V LDO + PG LED**

On `+3V3`, placed physically at the M.2 VCC pins: **2×470 µF/6.3 V polymer** (low-ESR) + **6×10 µF** ceramic + **0.1 µF per VCC pin (×8)** — this is the anti-brownout bank. Add 1.8 V LDO (`+3V3`→`+1V8`, **AP2112K-1.8**, SOT-23-5) with 1 µF in/out → feeds only `PCIE_DIS` (pin 20). Add power-good green LED + **330 Ω** on `+3V3`. (The HD3SS3220's VCC33 uses its own AP2112K-3.3 off VDD5 — see Task 4.)

- [ ] **Step 5: Run ERC (power sheet) + commit**

Run: KiCad → Inspect → Electrical Rules Checker (this sheet's nets).
Expected: 0 errors on `+3V3`/`+1V8`/`GND`/`VBUS_PD` (warnings for not-yet-connected downstream nets are OK).

```bash
git add -A && git commit -m "feat: power subsystem — PD sink, 4A buck to 3V3, 1V8 LDO"
```

- [ ] **Step 3: HD3SS3220 — CC + orientation + SS mux (standalone UFP)**

Place HD3SS3220. Straps: `PORT`(4)→GND, `ADDR`(22)→NC, `ENn_MUX`(12)→GND, `ENn_CC`(29)→GND via RC (~2 ms), `CURRENT_MODE`(3)→NC, `DIR`(11)→200 kΩ pull-up to VDD5; `VBUS_DET`(5) ← `VBUS_DATA` via **900 kΩ**; thermal pad + pins 13/28 → GND. ### Task 9: USB SuperSpeed + USB2 differential routing

**Files:**
- Modify: `em9293-carrier.kicad_pcb`

- [ ] **Step 1: Set diff-pair rules**

Board Setup → Net Classes: `USB_SS` and `USB2` = **90 Ω diff**, target width/gap from the Task-7 impedance profile. Assign `USB3_*`, `USB2_*` nets.

- [ ] **Step 2: Route SS pairs**

Route USB3 TX/RX pairs connector→mux→module **on L1**, referenced to the **solid L2 GND plane** (NOT L4 — that references the L3 power plane, a compromised return). Route D+/D- as a 90 Ω pair; CC lines and `CC_ORIENT` as normal signals; `VBUS_DATA` to pin 22 with the 33 Ω + ESD.

### Task 12: Bring-up test procedure (the integration test)

**Files:**
- Create: `hw/em9293-carrier/bringup.md`

- [ ] **Step 1: Power-only smoke test**

With no module seated: apply PD charger to J2. Verify `VBUS_PD` = 12 V (or 9 V), `+3V3` = 3.30 V ±3%, `+1V8` = 1.80 V, PWR LED on. Confirm ripple ≤100 mVpp on a scope. **Gate:** rails good before seating the $$ module.

- [ ] **Step 2: Enable + boot**

Seat EM9293 + screw down + attach 4 antennas + heatsink. Power J2. Verify pin 6 reads high (>1.35 V), pin 20 reads `+1V8`. **Green STATUS LED should blink** within seconds.

- [ ] **Step 3: USB enumeration**

Connect J1 → Mac. Verify `VBUS_SENSE` (pin 22) ~5 V. Run:
```bash
ioreg -rc IOUSBHostDevice -w 0 | grep -A2 '"idVendor" = 4505'   # Sierra 0x1199
ls /dev/cu.usbmodem*
```
Expected: Sierra device present; `cu.usbmodem*` ports appear. Test both USB-C orientations (mux check).

- [ ] **Step 4: AT + SIM + throughput**

Open the AT port; `AT`, `AT!ENTERCND="A710"`, `AT!GSTATUS?`, `AT!USBCOMP?` respond (no SIM needed). Insert SIM → `AT!GSTATUS?` shows registration. Run an iperf3 throughput test and compare against the RM551E reference.

- [ ] **Step 5: Commit the bring-up log**
